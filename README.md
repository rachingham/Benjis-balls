# Benji's Balls

The "coming soon" website for Benji's Balls: fetch balls designed in Sydney and tested by Benji the border collie.

Live at: https://benjisballs.com.au

## What's in here

| File | What it is |
| --- | --- |
| `index.html` | The website page: all the words and sections |
| `styles.css` | The look: colours, fonts, the "sticker" outlines and shadows |
| `images/benji-mark.png` | The Benji logo |
| `CNAME` | Tells GitHub Pages to use the domain benjisballs.com.au |

Colours and fonts come from the Benji's Balls Design System.

## Wording rule

The balls are made overseas, so never say "Made in Australia" or "Australian-made". Use "Designed in Sydney. Tested by Benji." instead.
